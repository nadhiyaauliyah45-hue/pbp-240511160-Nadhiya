# Analisis Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Arsitektur | Client-server; front-end di browser, back-end di server | Terpasang dan berjalan langsung di OS; umumnya event-driven | Terpasang di smartphone; event-driven; native atau cross-platform |
| Bahasa Utama | HTML, CSS, JavaScript; React, Node.js | Java (JavaFX), C# (.NET), Electron | Kotlin (Android), Swift (iOS), Flutter |
| Distribusi | Diakses lewat browser via internet; tanpa instalasi | Installer diunduh lalu dipasang di OS | Dipasang di smartphone, umumnya lewat toko aplikasi |
| Keunggulan | Tanpa instalasi; lintas perangkat; pembaruan terpusat | Dapat offline; akses penuh hardware | Akses sensor, GPS, konektivitas; portabel |
| Keterbatasan | Bergantung internet dan browser; akses hardware terbatas | Perlu instalasi dan pembaruan tiap perangkat; terikat OS | Layar dan sumber daya terbatas; native terpisah per OS |
| Contoh Aplikasi | Tokopedia, Facebook, Gmail | VS Code, Photoshop, Spotify | WhatsApp, Gojek, Instagram |
