REST API Sederhana dengan Express

LKP 4A · Pertemuan 6 · Nadhiya Auliyah Ramadhani (240511160)

API ini berjalan di komputer lokal pada http://localhost:3000 (jalankan npm run dev di folder lpk-4a). Data disimpan di array in-memory sehingga kembali ke data awal setiap server dimulai ulang. GitHub Pages hanya menampilkan halaman statis, sehingga halaman ini berisi dokumentasi.

Endpoint

GET/api/items200 OK
Mengambil semua item. 
{ "sukses": true, "data": [
  { "id": 1, "nama": "Laptop", "harga": 8000000 },
  { "id": 2, "nama": "Mouse",  "harga": 150000 } ] }
GET/api/items/:id200 / 404
Mengambil satu item berdasarkan id. 
GET /api/items/1
{ "sukses": true, "data": { "id": 1, "nama": "Laptop", "harga": 8000000 } }

GET /api/items/99   (404)
{ "sukses": false, "pesan": "Item tidak ditemukan" }
POST/api/items201 / 400
Menambah item baru. Body JSON wajib berisi nama dan harga. 
POST /api/items
{ "nama": "Keyboard", "harga": 300000 }

201 Created
{ "sukses": true, "data": { "id": 3, "nama": "Keyboard", "harga": 300000 } }

400 Bad Request (harga tidak dikirim)
{ "sukses": false, "pesan": "nama dan harga wajib diisi" }
PUT/api/items/:id200 / 400 / 404
Mengubah sebagian atau seluruh field item. 
PUT /api/items/1
{ "harga": 7500000 }

200 OK
{ "sukses": true, "data": { "id": 1, "nama": "Laptop", "harga": 7500000 } }
DELETE/api/items/:id200 / 404
Menghapus item berdasarkan id. 
DELETE /api/items/2

200 OK
{ "sukses": true, "pesan": "Item berhasil dihapus" }

Status code

CodeMaknaDipakai saat
200OKGET, PUT, DELETE berhasil
201CreatedPOST berhasil
400Bad RequestInput tidak lengkap atau tidak valid, JSON rusak
404Not FoundId atau alamat tidak ditemukan
500Internal Server ErrorGalat tak terduga pada server

Contoh respons di halaman ini disusun dari logika kode pada server.js. Hasil pengujian yang sebenarnya didokumentasikan pada laporan praktikum.
